Синтаксис CSS состоит из набора правил. Каждое правило включает селектор и блок объявлений, который записывается в фигурных скобках.
Селектор указывает, к какому элементу страницы нужно применить стиль. Внутри фигурных скобок записываются объявления. Каждое объявление состоит из свойства и значения, которые разделяются двоеточием. В конце объявления ставится точка с запятой.
Комментарии в CSS записываются между символами /* и */. Браузер не обращает на них внимания.
